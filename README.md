# Twitter en MongoDB · TP NoSQL

Página para exponer el Trabajo Práctico NoSQL de Base de Datos Aplicada (UCC 2026), etapa por etapa (5.1 a 5.8).

- `index.html`: la página completa (un solo archivo). Usa Chart.js y Google Fonts desde internet.
- `img/`: capturas de las pruebas de Docker Compose (5.8).

Se publica en Render como **Static Site**: Build Command vacío y Publish Directory `.`.
